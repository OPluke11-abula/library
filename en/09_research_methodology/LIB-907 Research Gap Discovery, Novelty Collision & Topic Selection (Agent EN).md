## 1. Conceptual Mental Model: Avoiding Sunk-Cost Collisions Under Compute Constraints

Three failure modes derail student teams and AI research agents alike `[FACT]`:
1. **Single-Anchor Tunnel Vision**: Mistaking one baseline's limitation for an unsolved field gap without checking concurrent top-venue works, causing fatal **Novelty Collision** months later `[DESIGN_DECISION]`.
2. **Solution-First Regularizer Engineering**: Designing new losses or architectural patches before running falsification pilots (`G1/G2`) to prove the hypothesized failure actually occurs `[FACT]`.
3. **Phantom Workstation Planning**: Scheduling multi-hour RTX 4090/A100 sweeps when actual execution runs on 4GB–8GB consumer laptops and bounded cloud credits `[SAFETY_BOUND]`.

---

## 2. Formal Methodology

### 1. Four-Pass Verification & The 15-Column Literature Collision Matrix `[DESIGN_DECISION]`
Before advancing any candidate research gap, relevant 2024–2026 primary literature must be verified directly (official PDF/DOIs/repositories, never second-hand summaries) across **15 required fields**:
1. `Paper` (Full title, authors, year, venue)
2. `Source` (DOI / arXiv ID / official URL)
3. `Problem` (Targeted scientific limitation)
4. `Mechanism` (Exact algorithm & mathematical formulation)
5. `Assumptions` (Implicit geometric, data, or distributional preconditions)
6. `Failure` (Known or suspected failure modes separated clearly)
7. `Evidence` (Exact paper Section / Table / Figure)
8. `Code` (Official repo & exact license)
9. `Dataset` (Train/Val/Test benchmarks)
10. `Metrics` (Primary metrics matching claims)
11. `Compute` (Explicit `AUTHOR_REPORTED` GPU hardware and runtime)
12. `Single_GPU_Repro_Risk` (Risk assessment for 4GB / 8GB / 16GB T4 environments)
13. `Novelty_Collision` (Mechanism overlap analysis against candidate directions)
14. `Confidence` (`VERIFIED` / `INFERRED` / `UNVERIFIED`)
15. `Actionable_Delta` (Verified remaining open question)

### 2. Three-Dimensional Collision Verdict & Representation Substitution Test `[DERIVATION]`
Evaluate every candidate direction across **Task & Protocol**, **Mechanism**, and **Evaluation** axes:
- **Representation Substitution Test**: Mask superficial domain phrasing (e.g., substituting "gradient variance" for "uncertainty score") and align mathematically with the 3 nearest concurrent papers; if the core update geometry or gating operator reduces to an existing baseline, adjudicate `DIRECT_COLLISION_DO_NOT_PURSUE` `[SAFETY_BOUND]`.
- Output one of three strict verdicts: `CLEAR_GAP`, `PARTIAL_OVERLAP_REQUIRES_SCOPING`, or `DIRECT_COLLISION_DO_NOT_PURSUE` `[DESIGN_DECISION]`.

### 3. Failure-First Gate Progression & Epistemic Firewall `[SAFETY_BOUND]`
Execute gates sequentially without skipping ahead to novel loss design:
- **`P0`**: Reproduce unmodified baseline environment, dependencies, and single-run timing/VRAM.
- **`G1`**: Zero-GPU CPU synthetic counterexample test.
- **`G2`**: Minimal single-run real-scene / split pilot measuring the failure hypothesis on independent GT (`if no measurable failure -> NO-GO / Pivot immediately`).
- **`G3`**: Multi-scene / `Scene-disjoint` statistics with $B \ge 1{,}000$ bootstrap intervals.
- **`Novelty Gate`**: Only after `P0+G1+G2` confirm a real gap is algorithmic design authorized `[SAFETY_BOUND]`.
- Never relabel `NOT_RUN` or `TEAM_ESTIMATE` runs as `MEASURED` or `PASS` `[SAFETY_BOUND]`.

## 3. Constrained-Compute Scheduling Principles (`4GB / 8GB / Single-GPU Cloud`)

- **Cache-Once, Ablate-on-CPU**: For post-hoc calibration, conformal bounds, or matching analysis, extract detector logits/distributions once on GPU into compact tensors, then execute rapid `20+/day` statistical ablations on CPU `[DESIGN_DECISION]`.
- **Single-Node Timeout Circuit Breakers**: Set explicit per-run wall-clock ceilings before launching heavy 3DGS / CUDA builds on cloud quotas; enforce pre-declared numeric `GO / HOLD / NO-GO` thresholds `[DESIGN_DECISION]`.

## 4. Executable Python Implementation: `ResearchGateAuditor`

```python
from dataclasses import dataclass
from typing import Dict, List, Literal

ProvenanceTag = Literal["AUTHOR_REPORTED", "TEAM_ESTIMATE", "REPRODUCED_BY_TEAM", "NOT_RUN"]
ConfidenceTag = Literal["VERIFIED", "INFERRED", "UNVERIFIED"]
CollisionVerdict = Literal[
    "CLEAR_GAP",
    "PARTIAL_OVERLAP_REQUIRES_SCOPING",
    "DIRECT_COLLISION_DO_NOT_PURSUE",
]


@dataclass
class LiteratureAuditRecord:
    paper_id: str
    source_link: str
    mechanism: str
    evidence_section: str
    compute_provenance: ProvenanceTag
    confidence: ConfidenceTag


@dataclass
class MinimalPilotGate:
    name: str
    execution_state: ProvenanceTag
    reported_status: str
    estimated_minutes_per_run: float
    max_budget_minutes_per_run: float
    collision_verdict: CollisionVerdict


class ResearchGateAuditor:
    """Enforces primary-source provenance, compute honesty, and collision stop-loss rules."""

    @staticmethod
    def validate_literature_matrix(records: List[LiteratureAuditRecord]) -> None:
        assert len(records) >= 1
        for rec in records:
            assert rec.paper_id.strip()
            assert rec.source_link.startswith(("http", "arXiv:", "10.")), f"{rec.paper_id} missing valid DOI/arXiv"
            assert rec.evidence_section.strip()
            assert rec.confidence in ("VERIFIED", "INFERRED", "UNVERIFIED")
            assert rec.compute_provenance in ("AUTHOR_REPORTED", "TEAM_ESTIMATE", "REPRODUCED_BY_TEAM", "NOT_RUN")

    @staticmethod
    def evaluate_pilot_stop_rule(pilot: MinimalPilotGate) -> Dict[str, str]:
        if pilot.execution_state in ("NOT_RUN", "TEAM_ESTIMATE") and pilot.reported_status in ("PASS", "MEASURED"):
            raise AssertionError(f"[SAFETY BREACH] {pilot.name} is {pilot.execution_state}, cannot claim {pilot.reported_status}")
        if pilot.collision_verdict == "DIRECT_COLLISION_DO_NOT_PURSUE":
            return {"decision": "NO_GO", "reason": "Direct 3D collision detected"}
        if pilot.estimated_minutes_per_run > pilot.max_budget_minutes_per_run:
            return {"decision": "HOLD", "reason": "Exceeds per-run compute time ceiling"}
        if pilot.execution_state != "REPRODUCED_BY_TEAM":
            return {"decision": "HOLD", "reason": "Awaiting actual P0/G2 empirical run"}
        return {"decision": "GO", "reason": "Passed collision, compute budget, and empirical verification"}


if __name__ == "__main__":
    sample_lit = [
        LiteratureAuditRecord("AffineGS_NeurIPS2026", "arXiv:2611.07709", "Local affine + guidedFilter", "Sec. 3.2 & Table 2", "AUTHOR_REPORTED", "VERIFIED"),
        LiteratureAuditRecord("D-FINE_ICLR2025", "arXiv:2410.13842", "FDR + GO-LSD", "Sec. 3 & Table 1", "AUTHOR_REPORTED", "VERIFIED"),
    ]
    ResearchGateAuditor.validate_literature_matrix(sample_lit)

    fraud_pilot = MinimalPilotGate("Fake_Claim", "NOT_RUN", "MEASURED", 10.0, 45.0, "CLEAR_GAP")
    caught_breach = False
    try:
        ResearchGateAuditor.evaluate_pilot_stop_rule(fraud_pilot)
    except AssertionError:
        caught_breach = True
    assert caught_breach

    col_pilot = MinimalPilotGate("Naive_Mask", "TEAM_ESTIMATE", "PENDING", 15.0, 60.0, "DIRECT_COLLISION_DO_NOT_PURSUE")
    res_col = ResearchGateAuditor.evaluate_pilot_stop_rule(col_pilot)
    assert res_col["decision"] == "NO_GO"

    pending_pilot = MinimalPilotGate("Fast_Calibration", "TEAM_ESTIMATE", "PENDING", 12.0, 30.0, "PARTIAL_OVERLAP_REQUIRES_SCOPING")
    res_pen = ResearchGateAuditor.evaluate_pilot_stop_rule(pending_pilot)
    assert res_pen["decision"] == "HOLD"

    print(f"[LIB-907 Verified] breach_blocked={caught_breach}, collision={res_col['decision']}, clean_pending={res_pen['decision']}")
```

## 5. AI Agent Inference Contracts & System Invariants

### [RULE-907-01] Zero Unverified Source & Compute Fabrication Invariant
- **Contract Level**: `SAFETY_CRITICAL`
- **Specification**: Every metric or compute duration must separate `AUTHOR_REPORTED`, `TEAM_ESTIMATE`, `REPRODUCED_BY_TEAM`, and `NOT_RUN` `[SAFETY_BOUND]`; unread paper fields must be marked `UNVERIFIED`, and `NOT_RUN` experiments must NEVER be reported as `MEASURED` or `PASS`.

### [RULE-907-02] Three-Dimensional Novelty Collision & Non-Repackaging Gate
- **Contract Level**: `CRITICAL_INVARIANT`
- **Specification**: Prior to algorithm engineering or full training, topics must undergo `15-Column` primary audits across `>= 3` nearest 2024–2026 baselines and pass the **Representation Substitution Test**; `DIRECT_COLLISION_DO_NOT_PURSUE` candidates must be blocked `[DESIGN_DECISION]`.

### [RULE-907-03] Minimal Pilot Numerical Stop-Loss Invariant
- **Contract Level**: `HIGH_INVARIANT`
- **Specification**: Every pilot must pre-declare baselines, leak-free splits, dependencies, and numeric `GO / HOLD / NO-GO` thresholds, executing strictly along `P0 -> G1 -> G2 -> G3 -> Novelty Gate` with immediate pivot on negative `G2` `[DESIGN_DECISION]`.

### [RULE-907-04] Compute Provenance & Constrained Hardware Truth Invariant
- **Contract Level**: `RESOURCE_CONSTRAINT`
- **Specification**: Agents must NOT assume unverified `RTX 4090 (24GB)` hardware for constrained student pipelines (`4GB–8GB` laptops / bounded single-GPU cloud quotas); workflows should decouple GPU feature caching from rapid CPU statistical ablation `[SAFETY_BOUND]`.
